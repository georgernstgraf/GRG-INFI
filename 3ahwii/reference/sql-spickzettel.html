SQL-Spickzettel UE 1–3

Nur was in den ersten drei Lessons vorkommt. SQLite-Dialekt.

Wiederholung (UE 1)

-- JOIN + Gruppierung + HAVING
SELECT a.name, COUNT(*) AS n
FROM artist a
JOIN track t ON t.artist_id = a.id
GROUP BY a.name
HAVING COUNT(*) > 5
ORDER BY n DESC;

-- Self-JOIN: Paare in derselben Tabelle
SELECT x.name, y.name
FROM artist x
JOIN artist y ON y.label_id = x.label_id
WHERE x.id < y.id;

-- COUNT-Falle
SELECT COUNT(*) AS zeilen, COUNT(label_id) AS mit_label
FROM artist;

Unterabfragen (UE 3)

-- Skalar in WHERE: ein Wert
SELECT title FROM track
WHERE plays > (SELECT AVG(plays) FROM track);

-- Tabelle in FROM: erst filtern, dann zählen
SELECT label, COUNT(*) AS n
FROM (SELECT * FROM artist WHERE active = 1) AS a
GROUP BY label;

-- Zeile in WHERE: ein Tupel vergleichen
SELECT name FROM artist
WHERE (label_id, active) = (SELECT id, 1 FROM label WHERE name = 'Indie');
Regel: Subquery in SELECT muss skalar sein (genau ein Wert pro Zeile). Subquery in FROM braucht in SQLite fast immer einen Alias (AS x).
